**1. What did you ask the AI to help you with, and why did you choose to use AI for that specific task?**

I asked the AI to help me debug errors in my backend server for my EventPlanner project and to help me understand what was causing my server to crash. I specifically needed help because I was getting terminal errors that I didn’t understand, like connection issues when trying to run my server and a “.keys required” error in my index.js file.
I also asked the AI to help me complete missing parts of my backend (like model functions and controllers) and to break down code line-by-line so I could understand what each part was doing instead of just copying it.
I chose to use AI because I was stuck on debugging errors quickly and I also wanted to actually learn what the code was doing instead of just guessing or copying without understanding.

**2. How did you evaluate whether the AI's output was correct or useful before using it?**

I evaluated the AI’s output by testing the changes directly in my terminal and checking whether the server started successfully or if the error messages changed. For example, when the AI suggested fixing the cookie-session configuration in index.js, I checked my code against the suggested fix and then restarted the server to see if it resolved the crash.
I also compared the AI’s explanations with my course reference apps and previous lecture examples to make sure the structure and SQL patterns matched what we learned in class.
If something didn’t work right away, I treated it as a sign that either I copied something incorrectly or I needed to re-check the file structure.

**3. How did what the AI produced differ from what you ultimately used, and what does that tell you about your own understanding of the problem?**

In some cases, the AI gave full code blocks, but I didn’t always use them exactly as written. I sometimes had to adjust variable names, file paths, or match the code to my existing structure so everything connected properly with my project.
For debugging, the AI would point me in the right direction (like identifying that the server wasn’t starting because of a configuration error), but I still had to locate the exact line in my index.js file and understand how cookie-session worked to fully fix it.
This shows that my understanding is still developing, especially with backend setup and error debugging, but I am getting better at recognizing patterns and connecting errors to specific parts of my code instead of being completely stuck.

**4. What did you learn from using AI in this way?**

I learned that AI is most helpful when used as a debugging and learning tool rather than just a code generator. It helped me understand how different parts of a backend system connect, especially models, controllers, and server configuration.
I also learned that reading error messages carefully is very important because they usually point directly to the file and line causing the problem. Using AI helped me translate those errors into something understandable so I could fix them myself.
Overall, I learned how to combine AI support with my own testing and reasoning instead of relying on it blindly, which helped me build both my project and my understanding of backend development.
